# 财经院校毕业去向分析 · 可视化系统

把「本科就业数据 → 研究生招生结构 → 院校学制差异」三层信息放进一个可交互的静态站点。

## 内容结构（7 个视图）

| 视图 | 看点 |
|---|---|
| 01 总览 | 6 个关键数字 + 金融业五年轨迹 + 会计职业收缩，三条结论 |
| 02 行业流向 | 2021—2025 届 12 个行业的就业占比折线（金融业、建筑业高亮）与条形对比 |

| 05 院校对照 | 11 所院校逐个官网核对的学制与项目结构，带三色验证徽章 |

## 数据来源

- **就业数据**：《2026 年中国本科生就业报告》（麦可思就业蓝皮书，社会科学文献出版社 2026 年 6 月第 1 版），基于 2025 届毕业生毕业半年后跟踪评价
- **研究生结构**：中央财经大学 2027 年硕士研究生招生章程与招生专业目录（66 条档案）
- **院校学制**：对外经贸、西南财经、中南财经政法、中国人民大学、清华五道口、北大光华、上交安泰、复旦经院、上财研究生院官网公开材料

## 技术说明

纯静态：HTML + CSS + 原生 JS，图表用手写 SVG 生成，**无任何外部依赖与 CDN**，
断网也能完整显示。文件结构：

```
index.html   页面结构与 7 个视图
style.css    样式（含移动端适配）
data.js      全部数据（集中一处，便于核对与更新）
app.js       渲染逻辑与 SVG 图表函数
```

## 标注规则

| 标记 | 含义 |
