## 覆盖面

不属于「金融 / 会计 / 审计」三类的部分，同样在页面里有完整数据：

- **财税系统**：财政学、税收学、税务专硕、资产评估、公共管理（财政税务学院 5 条）
- **统计与数据**：数量经济学、经济统计、金融统计与风险管理、应用统计（统计与数学学院 5 条）
- **保险精算**：保险学、精算学、保险专硕、社会保障（保险学院 5 条）
- **公共部门**：行政管理、教育经济与管理、城乡公共治理、公共管理全日制/非全（政府管理学院 5 条）
- **国际商务**：国际贸易学、国际商务（国际经济与贸易学院 2 条）
- **科技方向**：网络空间安全、计算机技术、人工智能、财经智能科学与技术、信息系统与信息管理（信息学院 5 条 + 人工智能研究院 1 条）
- **其他**：体育产业经济学、国防经济、区域与国别经济学、数智绿色金融、劳动经济学、教育经济与管理等

## 数据来源

- **全国本科就业**：《2026 年中国本科生就业报告》（麦可思就业蓝皮书，社会科学文献出版社 2026 年 6 月第 1 版），基于 2025 届毕业生跟踪评价
- **央财本科去向**：《中央财经大学就业数据支撑表》（2026 年 11 月编制），含 45 个专业清单、近三届去向结构、行业与地域分布
- **央财研究生**：2027 年硕士研究生招生章程与招生专业目录，66 条档案；2025 年录取数为简报口径
- **院校学制**：对外经贸、西南财经、中南财经政法、中国人民大学、清华五道口、北大光华、上交安泰、复旦经院、上财研究生院官网公开材料
- **岗位族与起薪**：岗位结构池参数（团队模型，非市场统计）

## 三类数据标记

| 标记 | 含义 |
|---|---|
| ● | 目录级事实：官网可回查，可直接引用并注明年份 |
| ▲ | 量级参考：区间口径，只用于判断方向，具体数字按最新报告核对 |
| ■ | 模型推演：团队参数，只能用于比较相对差异，不能写成统计结论 |

## 技术说明

纯静态：HTML + CSS + 原生 JS，图表用手写 SVG 生成，**无任何外部依赖与 CDN**，断网也能完整显示。

```
index.html   页面结构与 10 个视图
style.css    样式（含移动端适配与筛选按钮）
data.js      全部数据（集中一处，便于核对与更新）
app.js       渲染逻辑与 SVG 图表函数
```

## 本地查看

直接双击 `index.html` 即可，无需服务器。
